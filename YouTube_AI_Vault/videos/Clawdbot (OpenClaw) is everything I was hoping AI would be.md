## TL;DR
> A full walkthrough of setting up ClawdBot (now OpenClaw) on a Hostinger VPS: hardening the server with a dedicated user and SSH keys, installing Node.js and ClawdBot, onboarding it with a chosen LLM provider, connecting Telegram for messaging, and then using it to harden its own SSH config, add skills from ClawHub (including a Google Workspace CLI skill for Gmail), and set up cron/webhook-triggered automations.

**Watch this if:** you want a hands-on, security-conscious guide to standing up your own self-hosted AI agent from a bare VPS to a fully working personal assistant.

## Key Takeaways
- The presenter deploys Open Claw on a $6.99/month Hostinger KVM2 VPS (2 vCPU, 8GB RAM, 100GB SSD) instead of buying dedicated hardware like a Mac Mini.
- Before installing the bot, harden the VPS: create a dedicated non-root user, set up SSH key auth for it, and (cautiously) grant passwordless sudo — with the warning that this is risky and shouldn't be done on a machine you can't afford to lose.
- Onboarding offers several LLM provider options (Anthropic OAuth, OpenAI Codex/API key, Google Gemini, Antigravity); Claude Max previously worked but Anthropic began blocking third-party harnesses, so the presenter uses a ChatGPT Plus plan via OpenAI Codex OAuth instead.
- Once running, the bot can be tasked to secure itself: asked (with explicit confirmation required) to review and harden its own SSH config, and it correctly disabled root login and password auth while preserving key-based access.
- Skills — Markdown "recipe cards" that narrow down what an LLM should do for a specific tool — are installed from ClawHub; the bot can search for, download, and manage its own skills, including a Google Workspace CLI skill it used (after working around a missing Homebrew dependency by pulling the binary from GitHub) to authenticate with Google and summarize Gmail messages.
- The bot supports multiple trigger types beyond chat messages: cron-based scheduling (e.g. checking flight prices twice daily), webhooks (e.g. notifying on a Polar purchase), OAuth-expiry monitoring, Gmail push notifications, and plain polling.
- Recommended practices: don't run it on production/critical hardware since it's an LLM and will sometimes do the wrong thing; use Git plus a GitHub skill to version-control and back up the bot's configuration (without committing secrets); and use a secrets manager like Doppler rather than pasting passwords through the chat interface.
