## TL;DR
> Anthropic added scheduled tasks to Claude Cowork, letting prompts run automatically on a recurring basis. The video walks through real daily-use workflows (business briefs, Stripe reports, Substack note drafting, nightly brain-dump organization), shows how to set up scheduled tasks in Cowork, and then demos a free open-source Claude Code plugin that brings the same cron-based scheduling natively to Claude Code without needing the Cowork app to stay open.

**Watch this if:** you want AI agents to run recurring work (reports, cleanup, content drafts) automatically in the background, in either Claude Cowork or Claude Code.

## Key Takeaways
- Scheduled tasks are just prompts Claude runs on a schedule you set (hourly, daily, weekday, weekly, or manual/on-demand).
- Real daily workflows demoed: a business brief (Google Calendar meetings, unread email triage, overnight Sentry errors), a daily AI news brief, a weekly Stripe sales report, daily Substack note drafts written in the creator's voice using specific Claude Code skills, and nightly brain-dump organization into a personal context system.
- With Playwright MCP for browser control, a scheduled task could go as far as automatically posting drafted notes to Substack at set times, though the presenter prefers a staging area to review/tweak first.
- Anthropic's own recommended use cases include recurring competitor research, folder/file auto-organization, and team status updates via email/Slack/Discord.
- In Cowork, scheduled tasks require both your computer and the Cowork app to be running — if either is off, the task is skipped (with a best-effort catch-up attempt on next app open), which is a real limitation.
- Cowork tasks let you pick the model (e.g., Sonnet 4.6 instead of Opus for simple tasks) and the working directory, since Cowork spins up a local VM based on that directory.
- The presenter's free "AI Launchpad Marketplace" plugin brings the same scheduling to Claude Code natively, using the OS's built-in cron and a bundled skill so Claude knows how to create/manage scheduled tasks just from a plain-language request — and it runs without needing any app to stay open.
- The plugin stores tasks in a per-project `.claude/scheduler` folder with a `registry.json` (all tasks), `logs/` (per-run logs), `results/` (default output location), and `wrappers/` (the actual generated scripts that invoke Claude Code with the task's prompt).
