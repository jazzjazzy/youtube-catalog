## Key Takeaways
- Marketing Skills for AI Agents (by Corey Haines) is a free, open-source, ~35-skill collection covering CRO, SEO auditing, copywriting, analytics setup, pricing strategy, cold email, and more — over 20,000 GitHub stars, MIT licensed.
- Install with one NPX command; it clones the repo, lets you checklist which of the ~35 skills to install, pick your agent(s) (Claude Code, OpenCode listed separately/universally), and choose project-level vs. global installation.
- Product Marketing Context is the foundational skill to run first — it scans your codebase, landing page, and README to build a context document (product description, ICP, positioning, differentiators, competitive landscape, messaging) that every other skill reads before running.
- Page CRO audits a landing page section by section (headline, CTA placement, social proof, pricing, form design, above-the-fold content) with specific, actionable recommendations rather than vague advice.
- The Copywriting Skill uses the product context and CRO audit together to rewrite landing page copy section by section, producing multiple variations per section following direct-response principles.
- Content Strategy builds a content calendar with pillars, topic clusters, and prioritized post ideas with search intent and target keywords, tailored to the product and audience.
- AI SEO optimizes content specifically to get cited/referenced by AI search engines and chat assistants (ChatGPT, Perplexity, Gemini, Claude) rather than just traditional search engines — an early-mover advantage most people aren't optimizing for yet.
- Skills cross-reference each other in the repo (copywriting ↔ page CRO, RevOps ↔ sales enablement/cold email, SEO audit ↔ schema markup/AI SEO), so installing and using more of them compounds output quality.
- These skills are a first-draft accelerator, not a replacement for a real marketer — outputs still need review, prioritization, and brand-fit judgment.

Most developers can build a product in a weekend now — that's not the hard part anymore. The hard part is getting people to know your product exists. Solo founders and indie developers often know how to code but have no idea how to write converting landing page copy, set up analytics, run a proper SEO audit, or plan a content strategy — and hiring a marketer or agency is expensive when starting out.

Marketing Skills for AI Agents, built by Corey Haines, is a free open-source project that gives a coding agent actual marketing knowledge. It works with Claude Code, OpenCode, Cursor, Codex, Windsurf, and basically any agent supporting the agent skill spec. A skill is a markdown skill.md file containing structured instructions, frameworks, and workflows for a specific task — like giving the agent an expert's playbook instead of prompting from scratch every time. These are proper structured marketing frameworks: conversion rate optimization, SEO auditing, copywriting, analytics setup, pricing strategy, email sequences, and more. The GitHub repo has over 20,000 stars, is MIT licensed, and currently has around 35 marketing skills.

To install, run one command: it clones the repo, scans for available skills, and presents a checklist of all ~35 (AB test setup, ad creative, AI SEO, analytics tracking, churn prevention, cold email, competitor alternatives, content strategy, copywriting, and more) — toggle with spacebar. Then it asks which agent to install to (OpenCode is listed under "universal agent," Claude Code under "other agent" — you can pick one or both), then whether to install at project level (only that project) or globally (every project). For OpenCode, the same NPX command installs skills into a `.agents/skills` directory; OpenCode also checks `.claude/skills` for cross-compatibility, and reads skills on demand through a native skill tool, loading them only when needed.

Once installed, skills show up as slash commands (e.g., typing `/page-cro`), or the agent auto-detects and loads the relevant skill based on your prompt (e.g., "help me optimize this landing page for conversions" triggers Page CRO automatically).

The key to how these skills work together is the foundational Product Marketing Context skill — the first one to run. It scans your project, codebase, landing page, and README to build a context document covering what your product does, your target audience, your positioning, and your value proposition. Every other skill reads this context file first: the copywriting skill knows your product/audience/positioning before writing; the SEO audit skill understands which keywords matter for your niche.

Live demo: running `/product-marketing-context` analyzes the codebase, landing page, and README, producing a markdown file with product description, ideal customer profile, positioning statement, key differentiators, competitive landscape, and messaging framework — asking clarifying questions as needed, after which every other skill references it automatically.

Next, Page CRO is run against a landing page: the agent reads the whole page and produces a detailed audit covering headline structure, CTA placement, social proof, pricing layout, form design, above-the-fold content, and overall page flow — with specific actionable recommendations (e.g., a too-vague headline, a CTA below the fold, a suggested testimonial placement) rather than vague advice.

The Copywriting Skill is run next, rewriting landing page copy section by section using both the product marketing context and the Page CRO audit — output organized by section (new headline, sub-headline, hero, feature descriptions, CTA, social proof), each with multiple variations following direct-response principles (short sentences, clear benefits, specific outcomes, strong CTAs).

Content Strategy plans a content calendar based on product and audience — content pillars, topic clusters, and individual post ideas (e.g., for a SaaS product: core problem space, solution, industry trends, customer success stories), each with search intent, target keywords, and prioritization by potential impact.

AI SEO is worth mentioning too: as traditional SEO gets harder for small sites, this skill optimizes content structure so it's more likely to be cited or referenced by AI search engines and assistants — ChatGPT, Perplexity, Gemini, and Claude — when people ask them questions. Most people aren't thinking about this yet, so it's an early advantage.

For B2B, the Cold Email skill takes a target persona and value prop and produces a multi-email sequence with personalization hooks, follow-up timing, and subject-line variations, focused on short, direct messages more likely to get replies.

These skills don't replace a real marketing strategy or marketer — they're tools to execute faster with a solid starting framework. The output is good, sometimes really good, but still needs review (e.g., picking the headline variation that matches your brand, prioritizing which of 30 suggested blog topics to write). Skills also cross-reference each other within the repo (copywriting ↔ page CRO, RevOps ↔ sales enablement/cold email, SEO audit ↔ schema markup/AI SEO) — the more skills installed and used, the better the compounding output. The repo is open to contributions via its contributing.md guidelines.

To recap: run one NPX command, pick your skills, choose your agent, pick project or global install, and you're ready — free, open source, and works with tools you already use. Start with Product Marketing Context, then use whatever matches your current need (launch strategy for launching, Page CRO for conversion optimization, Content Strategy for content needs).
