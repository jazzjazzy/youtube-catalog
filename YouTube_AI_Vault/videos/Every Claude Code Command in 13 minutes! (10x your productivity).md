## Key Takeaways
- Tier 1 (non-negotiable): `/login`, `/doctor` (diagnoses install issues), `/init` (creates claude.md for persistent project context — "the one thing to take from this video"), `/config`/`/settings`, `/help`.
- Tier 2 (session management): `/clear`/`/reset`/`/new` to wipe context; `/model` to switch models mid-session (Haiku for easy/cheap, Sonnet for most tasks, Opus for complex/multi-agent); `/cost`/`/usage`; `/permissions`/`/allowed-tools`; `/compact` (trims history without fully clearing it); `/context` (visualizes context window fill); `/plan` (planning mode before Claude takes action).
- Tier 3 (building/review): `/diff`, `/rewind`/`/checkpoint`, `/fork` (branch the conversation to try parallel approaches), `/memory` (edits claude.md to record recurring mistakes/preferences), `/security-review` (scans pending changes for vulnerabilities/leaked secrets before every code review, not just big ones), `/simplify` (spawns 3 parallel review agents to clean up recently changed files), `/tasks`, `/btw` (side question without polluting main context), `/debug` (reads the session log, optionally focused on a specific issue).
- Tier 4 (power user/agent): `/mcp` (connect to third-party platforms like Notion, Slack, Google Drive via MCP servers), `/bash`, `/loop` (run a prompt repeatedly on an interval — babysitting PRs, retrying failing tests, watching an API), `/claude-api` (auto-activates when it detects Anthropic SDK imports), `/plugin`, `/agents` (multi-agent configuration), `/hooks` (automated actions on tool events), `/reload-plugins`, `/skills` (lists from 60,000+ available skills).
- Tier 5 (workflow/output): `/export`, `/copy`, `/pr-comments` (fetch GitHub PR comments into session), installing the GitHub App (Claude GitHub Actions integration) and the Slack App (via OAuth, so Claude can work inside Slack).
- Tier 6 (IDE/environment): `/ide`, `/add-dir`, `/desktop`, `/terminal-setup`, `/keybindings`, `/sandbox` (isolated execution mode).
- Tier 7-8 (personalization/info): `/theme`, `/color`, `/status-line`, `/vim`; `/status`, `/stats`, `/insights`, `/release-notes`, `/effort` (low-to-max reasoning depth), `/fast`, `/privacy` (Pro/Max only).
- Tier 9-10 (rarely used/deprecated): `/rename`, `/resume`/`/continue`, `/remote-control` (control a session from Claude AI remotely), `/remote-env`, `/feedback`/`/bug`, `/extra-usage`, `/passes` (gift a free week), `/chrome` (Claude in Chrome browser agent), `/mobile`, `/upgrade`, `/logout`, `/exit`/`/quit`; `/review` is deprecated (now points to the code-review plugin) and `/stickers` just orders physical stickers.
