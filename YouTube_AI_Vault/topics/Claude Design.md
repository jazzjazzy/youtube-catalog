# Claude Design

Claude Design is Anthropic's design-focused Claude product: give it a prompt, codebase, Figma file, or brand assets and it returns a working prototype, slide deck, one-pager, landing page, or animation, with hand-off to Claude Code to ship. Found in the Claude sidebar or at claude.ai/design.
